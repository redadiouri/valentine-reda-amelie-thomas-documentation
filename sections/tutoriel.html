Contribuer au projet

Suivez ces étapes pour proposer une modification dans de bonnes conditions.

  1. Mettez à jour la branche principale, puis créez une branche adaptée à votre tâche.

    git switch main
git pull origin main
git switch -c docs/nom-de-la-tache

  2. Modifiez les fichiers concernés et vérifiez les changements avant de les enregistrer.

    git status
git diff

  3. Ajoutez les fichiers utiles et créez un commit avec un message précis.

    git add chemin/du-fichier
git commit -m "docs: décrire la contribution"

  4. Publiez votre branche sur GitHub. Pour son premier envoi, utilisez :

    git push -u origin docs/nom-de-la-tache

    Ouvrez ensuite une pull request vers main, décrivez vos changements et demandez une relecture.

  5. Traitez les retours de relecture, envoyez vos corrections sur la même branche, puis faites fusionner la pull request après approbation.

    git push

Bonnes pratiques

Quelques règles simples rendent le travail d’équipe plus clair et plus sûr.

  • Faites des commits courts, cohérents et consacrés à un changement précis.
  • Rédigez des messages de commit qui expliquent clairement la modification.
  • Relisez votre travail et faites relire chaque pull request avant sa fusion.
  • Vérifiez les fichiers modifiés avec git status et git diff avant de les ajouter.
  • Ne publiez jamais de mot de passe, de clé API ou d’autre secret dans le dépôt.
  • Échangez avec l’équipe si plusieurs personnes travaillent sur les mêmes fichiers.
